How to install

  1. Tap Download the app above.
  2. Your phone will ask — tap Download anyway.
  3. When it finishes, tap the downloaded file.
  4. Your phone will mention “unknown apps” — go to Settings and Allow.
  5. Tap Install. That’s it.

The first time you open it

  1. Type the mobile number we have on your account.
  2. We text you a 6 digit code — type it in.
  3. You’ll see today’s photo with the time it was taken, and what was done.
  4. Below that: your plan, what you owe, and a Pay button.
  5. More than one car? Tap the tabs at the top to switch between them.

What else it does

  1. The last eight days of photos, so you can look back.
  2. Report a problem — it reaches us straight away.
  3. Skip tomorrow — one tap, no phone call needed.

The app updates itself — you never need to install it again. You stay signed in, so the code is asked for only once.
