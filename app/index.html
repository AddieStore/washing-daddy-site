Chotte aur Shahrukh ke liye. Ek baar install karo, roz ka kaam phone mein.

App download karo

Install kaise karein

  1. Upar wala App download karo button dabaiye.
  2. Phone poochhega — Download anyway dabaiye.
  3. Download poora hone par file par tap kijiye.
  4. Phone kahega “unknown apps” — Settings → Allow kar dijiye.
  5. Install dabaiye. Ho gaya.

Pehli baar kholne par

  1. Apna naam chuniye — Chotte ya Shahrukh.
  2. Aaj ki poori list aa jayegi, har car ka time ke saath.
  3. Car par tap karo, timer apne aap chalu.
  4. Photo lo, Ho gaya dabao, agli car.

App apne aap nayi hoti rehti hai — dobara install karne ki zaroorat nahi. Signal na ho to bhi kaam chalta hai; photo aur tick phone mein ruk jaate hain aur signal aate hi apne aap chale jaate hain.
