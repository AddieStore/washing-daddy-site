Install on Android

  1. Tap Download for Android. If Chrome warns, tap Download anyway.
  2. Open the downloaded file.
  3. If the phone says unknown apps, tap Settings, turn on Allow from this source, and go back.
  4. Tap Install, then Open.

Install on iPhone

  1. Open this page in Safari and tap Open in Safari for the app you want.
  2. Tap the Share button (the square with an arrow).
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Open it from the home screen. It runs full screen like any other app.
